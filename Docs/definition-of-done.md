# Definition of Done

Tehtävä on valmis, kun kaikki kohdat täyttyvät:

- [ ] Ominaisuus täyttää vaatimusmäärittelyn vaatimuksen ja toimii myös virhetilanteissa.
- [ ] Koodi on viety pull requestilla `main`-haaraan, ja toinen ryhmän jäsen on hyväksynyt sen.
- [ ] Ominaisuus on testattu selaimessa tietokoneella ja puhelimen kokoisella näytöllä.
- [ ] Tehtävä on merkitty valmiiksi tehtävätaululla.
